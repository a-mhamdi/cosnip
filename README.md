# Code Snippets Collection (`cosnip`)

This repository is a curated collection of interesting code snippets, scripts, and small examples gathered over time. 

The snippets in this repository are **not logically connected** to a single unified project or framework. Instead, this repo serves as a personal codebase and reference bank where I keep code that I:
- **Learned from** during study, research, or exploration.
- **Reference** when I need a quick implementation or standard pattern.
- **Use for teaching and sharing**, to explain concepts, guide others, or provide useful code examples.
